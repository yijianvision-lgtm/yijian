## 2. 产品现行基准

- 产品中文主名：观复；英文副名：Mind；NEBULA 为工程/仓库代号。
- 核心定位：认知定位与知识过滤，服务个人思维框架建立；不是普通脑图或仪表盘。
- 最高认知顺序：**定其位 → 联其缘 → 生其相 → 归其一**。
- 四向四维是一体：以中心题眼为核心，保留原有四向名称**瞻前、顾后、左顾、右盼**；前源、左体、右用、后流是四侧语义解释，不得将四向和四维拆成两套独立系统。
- 框架与层级贯穿四侧；历史时点、当时世界、周围对象及关系证据是展开上下文。
- 树、网、时间、世界/空间和三维宇宙是不同视图/表达，不是互相替代的唯一知识本体。
- 知识对象需稳定身份、多对多有类型关系、来源证据、框架上下文、探索路径与版本可追溯。
- AI 只提出候选/提案；正式知识变更必须由用户审核确认。
- Local-first；默认本地保存；原始资料与提取结果分离；不得静默覆盖、合并或丢弃原件。

## 3. UI方向与验收原则

- 主视觉优先级：A「纯宇宙画布」；B「认知控制台」吸收操作效率；C「纵向谱系工作台」吸收结构表达，不视为同等优先的替代主方向。
- 已确认通过的视觉/交互项必须锁定；新改动只针对明确未通过项。
- 代码提交、静态检查、自动化测试、真实浏览器测试、用户视觉验收、CI、部署和线上验证是不同证据，不得互相替代。
- 未经用户满意验收及明确授权，不得修改正式入口、正式后台、正式数据或生产发布配置。
