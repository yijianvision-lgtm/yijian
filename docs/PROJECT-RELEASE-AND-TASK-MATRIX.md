## 3. 学习状态菜单问题：源码证据与待测项

源码检查可确认：

1. 菜单开关存在一个 click listener。
2. 菜单选项保存存在一个 click listener。
3. 文档级 outside-click 关闭存在一个 listener。
4. 开关点击处理同步切换 `hidden`，并更新 `aria-expanded`。
5. V42.7 最后覆盖规则将菜单的 `backdrop-filter` 设为 `none`，并将显示动画设为 100ms opacity。
6. 较早版本 CSS 中仍存在 24px backdrop blur，但 V42.7 更高优先级的 ID 选择器覆盖了该属性。

因此，重复监听器目前不是已证实原因；仅从源码也不能断言菜单已修复。下一步必须在真实浏览器记录点击事件时间、菜单首次可见时间、命中测试结果及 style/layout/paint 耗时。若延迟仍存在，再检查覆盖层、点击热区和主线程任务。不得仅通过静态检查宣布通过。
